InboxGuard

Ask an email assistant something, slip a malicious email into its inbox if you like, and see what it does under each defence.

Everything here is simulated: a fake student inbox with fake secrets. Nothing is really sent or deleted, and every run starts from a fresh copy of the inbox.

It arrives in the inbox as a new email from a stranger. Pick an attack to try, or write your own.

3. Choose a defence

Results appear here: what the agent changed in the inbox, its answer, and every step it took to get there.

A good first try: pick Steal a code under step 2, then press Compare all three defences.

    Model calls go through the course proxy (gemma-4-E4B-it, temperature 0), so a run takes a few seconds per step and the same input can occasionally give a different result. Source code and evaluation: github.com/HeRoExXD-code/inbox-guard
